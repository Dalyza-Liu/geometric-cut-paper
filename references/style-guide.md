# 本系列的视觉规则

`assets/vegetable-reference.png` 是主要风格基准：绿色蔬菜、鲜明橙黄、柔和多边形和少量曲线、局部深色叠印、轻微点纹。参考图带米黄色底，仅用于观察配色；导出的独立素材和组合总览均为透明背景，不复制底色。`assets/grocery-reference.png` 是早期题材草稿，不是已认可的造型基准。参考决定表现方式，不决定新物品的内容，也不强制沿用原构图。

`assets/leaf-reference.png` 是用户追加的造型参考：以少数不规则多边形组成叶片，亮绿上面、较柔和的绿色下面、深绿中央折面。借鉴其折面与三层绿关系，背景透明，不复制参考背景的底色或明暗变化。

`assets/fruit-shape-reference.png` 和 `assets/cash-shape-reference.png` 展示当前要求的大色块与圆角、切角变化。水果用宽缓圆弧表现部分肩部和外缘，同时保留斜切底边及大面积叠色；纸币把圆形标记与倾斜纸片结合。这些例子用于判断形态和细节程度，不要求新物品照搬位置、数量或轮廓。两张参考均为透明背景。

`assets/latest-reference.png` 是用户确认保留的最新四件组合，组件已同步到素材库：牛奶、叶子、酸奶、牛肉。酸奶采用端正的上宽下窄杯身、贴合杯口的平封膜和短拉片。它取代旧的掀盖版本；当前组件可直接复用，其他旧食品仍按目录状态检查。

## 色板和叠色

数值在 `assets/style.json` 统一维护。优先使用一个主色、邻近的第二色和少量强调色，而不是每件物品都铺满全部色板。奶制品的浅色和牛肉的红色是先前草稿的补充色，不代表用户已认可旧造型。

用户要求保留品牌辨识时，可在场景的 `extraColors` 声明专用补充色。保留重要色相，同时降低过强的饱和度、调整明度与冷暖；文字和夹心等浅色优先用已有奶油色，深色保持适度暖调，避免整件包装突兀地比蔬菜组更冷、更亮或对比更强。调整仅作用于指定物件，不改全局色板影响其他素材。

奥利奥的具体约束：盒子需要蓝色与清晰的 OREO 字样，饼干保持深棕色；可把亮蓝与纯白调整得柔和、略偏青和偏奶油色。不要改回绿色盒子。这个案例说明应保留识别线索，不要求其他品牌都使用蓝色或相同文字。

叠色是明确的局部形状，例如叶片相交处深绿、绿色叶柄覆盖橙色根部的橄榄色、浅色瓶体侧面的较深绿。不要用一层统一黑色透明阴影或模拟光照取代它。需要画深度时保留平面色块，不做亮面塑料或金属反光。

## 造型

先取主要外轮廓、典型结构和少数辨认线索，用少量宽大的纸片构形，删减零碎轮廓转折和装饰。抽象程度可以高于照片，但形态仍应可辨认；包装与器物应保留能理解的结构。

轮廓混用宽缓圆弧与斜切边缘、少量折角。曲线用于适合圆润的肩部、果腹或圆形标记，直线保留手切纸片的方向感；允许同一物品的一侧较圆、另一侧较直。用少量贝塞尔曲线表达宽大的弧面，不把整组都画成密集折线，也不对所有角统一倒圆。圆与角的比例随对象变化，无须每件套用相同公式。

通过不同大小的纸片、不对称外轮廓和错开的交叠位置形成变化。交叠处保留明确的第三种颜色，优先用宽大的局部色面，而非每件都沿中轴加一条窄带。保持二维剪纸感，不用高光或阴影模拟立体。不要为了“可爱”增加脸、眼睛或四肢。

用户对早期试做的反馈是造型缺少几何色块、叠色和轻微颗粒；当前四件组已根据该反馈重画。验收时三项分别检查，不能只核对色号。不要用水滴或水果小标志代替包装本身的造型，也不要用圆滑白描边表达整块肉的形状。酸奶的几何化必须服从杯子结构：封膜是贴合杯口的扁平多边形，杯身中轴端正，不为追求折面而扭歪或画成叶片盖。

先用不规则大色块建立物品，再把两块纸的交叠区域设计成独立路径，最后在各色块内部加入可见但轻微的点纹。复杂结构可以简化，识别线索与纸片之间的关系必须清楚。颗粒不能只在放大数倍后才能发现，也不要粗到成为花纹。

## 复杂商品的简化程度

目标是与蔬菜插画的信息量一致，而不是照搬包装照片。先保留盒体或托盘轮廓、必要的品牌色和字样、少数可辨认的食品；省略次要小袋、密集配图、营养信息、细碎纹样、写实光影和细小装饰。饼干等可只用上下两片、浅色夹心和少数大色面表现，无需雕花或大量点状装饰。保留统一的轻微颗粒，不能因简化而删掉几何色块和叠色。

已有品牌信息与无关包装信息要分别判断：用户强调的 OREO 字样必须保留，其他复杂文字可以省略。局部修改遵守保持项，例如只改饼干盒的配色时，鸡肉托盘、布局和轮廓不变。当前新配色在用户确认前仍为候选，不自动替换已确认素材库。

纸盒需要能理解的折顶和侧面；瓶子需要瓶盖、瓶颈和瓶肩；牛肉用不规则肉块和奶白脂肪；面包保留外形和切痕；鸡蛋用偏圆的锥形；奶酪以楔形和少量孔洞辨认。新物品采用合适的识别线索，不照搬这些示例。

## 颗粒

采用固定 LCG 种子 84319、112 单位方形纹理和 780 个微小矢量圆点，其余参数从 JSON 读取。纹理沿物件填充，透明区不能残留孤立颗粒。放大物件时连同纹理一起缩放，避免颗粒粗细突然变化。

PNG 渲染器可在内存中缓存点纹以提升速度；保存的 SVG 仍保留原生矢量圆点，不保存成嵌入纹理位图。

把新物品与参考放在相近显示尺寸下比较：识别是否清楚，色板是否一致，细节是否太密，有没有粗黑轮廓、强立体高光、渐变或阴影，颗粒是否只在色块内。固定色值和点纹不能保证新物品造型的质量，仍需实际看图判断。
