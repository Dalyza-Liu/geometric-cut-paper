# image2editable 的定向改编

来源：[guangzhaoli/image2editable](https://github.com/guangzhaoli/image2editable)，MIT License。版本与来源路径见 `upstream-provenance.json`，版权许可在根目录 `LICENSE`。

本 skill 是面向用户超市插画系列的自包含改编，不是上游的官方预设，也没有安装其整套科研/海报工作流。

保留上游 `SKILL.md`、`references/reference-style.md` 和 `references/spec-renderer.md` 的原则：实际查看参考；区分内容、风格和修改目标；已有原生对象优先复用；简单图允许直接矢量绘制；统一输入并记录几何、配色和保持项；分别检查辨认、视觉和可编辑性；不把结构检查等同视觉验收或原生应用验收。

本次定制把开放式样式研究替换为已接受的蔬菜色板、点纹参数和形状规则。原生 SVG 管理几何，轻量场景清单管理位置；不使用上游科研图 spec 或 PPTX 后端。附带组件库与本次编写的组合、导出脚本；目录区分已确认版本与早期草稿，不能把全部示例都当作用户认可的造型。当前四件组合使用最新牛奶、叶子、贴合封膜的直立酸奶杯和牛肉。默认交付透明独立素材和透明组合总览，不强制先生成位图或选择外部设计软件。

上游更新不会自动修改本 skill 的风格和资源。
